# Custom "page not found" page

## Description
As a docs author, I want to write my site's own "page not found" page, so that it can point readers to the pages that help them most.

## Why
- Sites can change the text of Mordoc's "page not found" page, but not the page itself, for example to add links to popular pages or a way to contact support.

## What
- A site can write its own "page not found" page as a normal content page, and Mordoc shows it in place of its own.
- It builds on [the "page not found" page for broken addresses](../fix-not-found-page/proposal.md).
