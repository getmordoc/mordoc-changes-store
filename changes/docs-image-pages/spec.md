# Document images and advanced images: Specification

**Proposal:** [proposal.md](./proposal.md)

## Acceptance Criteria
- **AC-001:** Given the documentation, when a reader opens the page on writing advanced images, then it shows how to add one with a caption, that it opens larger on click or Enter, that it stands on its own line, and a working example.
- **AC-002:** Given the documentation, when a reader opens the page on styling images, then it lists only the settings of the plain image.
- **AC-003:** Given the documentation, when a reader opens the page on styling advanced images, then it lists every setting of the advanced image, with an example.
- **AC-004:** Given the navigation, when a reader looks under writing content and under styling, then each shows Advanced images right after Images.
- **AC-005:** Given the German documentation, when a reader opens these pages, then they say the same in German.
- **AC-006:** Given the documentation, when it is built with the Mordoc release that has advanced images, then the build finishes and reports no problems.

## Functional Requirements
- **FR-001:** A reader can learn how to write an advanced image: its caption, opening it larger, and that it stands on its own line, with an example.
- **FR-002:** A reader can learn how to style each kind of image, and that both share one style file.
- **FR-003:** Both new pages can be found in the navigation, in every language.

## Non-Functional Requirements
- None

## Boundaries
- None

## Constraints
- The documentation describes the Mordoc release that has advanced images, so it is published together with that release.
