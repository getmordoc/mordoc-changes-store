# Document images and advanced images

## Description
As a Mordoc user, I want the documentation to explain both the plain image and the advanced image, so that I can choose the right one and style it.

## Why
- Mordoc now has two kinds of image: a plain Markdown image, and an advanced image with a caption and click to enlarge. The documentation only describes the plain image.
- The documentation still says the plain image has a caption and click to enlarge, and lists styling settings that now only apply to the advanced image.

## What
- A page on writing advanced images, next to the page on writing images.
- The page on writing images also shows the image tag.
- A page on styling advanced images, next to the page on styling images, which keeps only the settings of the plain image.
- Both new pages in the navigation, and every page in English and German.
