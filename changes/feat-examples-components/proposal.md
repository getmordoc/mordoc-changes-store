# Components example site

## Description
As a Mordoc contributor, I want a small example website that shows every component and page type in Mordoc's default look, so that I can see them all working in one place.

## Why
- There is no single place to see every component and page type working.
- The [browser tests for this site](../test-e2e-components/proposal.md) need a site to test.

## What
- A small example site with every component and page type, in Mordoc's default look.
- One of four example sites, next to [themes](../feat-examples-themes/proposal.md), [localization](../feat-examples-localization/proposal.md) and [APIs](../feat-examples-apis/proposal.md).
- Every page is short: a sentence or two on what the feature is, then the feature itself.
