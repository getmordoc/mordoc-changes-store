# Mermaid diagrams

## Description
As a docs author, I want to use Mermaid diagrams in my pages, so that I can bring my existing diagrams to Mordoc and write new ones in a format I already know.

## Why
- Mermaid is the most used format for diagrams in markdown, and teams moving from other documentation tools often have Mermaid diagrams.
- Mordoc only supports its own sequence diagrams today.

## What
- Mermaid diagrams written in a `mermaid` code block, shown in both the light and the dark theme.
- Mermaid is installed only by sites that use it, and Mordoc gives a clear message when it is missing.
- Mordoc's own sequence diagrams stay as they are.
