# Pull request template in every repository

## Description
As a Mordoc contributor, I want every pull request to start from the same template, so that reviewers can check that a pull request matches its change and contains nothing more.

## Why
- Only the change documents repository has a pull request template. Pull requests in the code, docs and app repositories start empty, so what they describe and how they link to their change differs each time.
- Reviewers can only check a pull request against its change when the pull request says what it does, why, how it is built and how it was tested.

## What
- The same pull request template in every Mordoc repository: the code, the documentation, the app starter and the change documents.
- The template is the one already used in this repository, as the sample: [pull request template](../../.github/pull_request_template.md). It links to the change, and asks for a description, the solution, the type of change, the tests and before and after visuals.
