# Repository basics

## Description
As a visitor of Mordoc's repositories, I want every repository to say what it is for and who holds the copyright, so that the project looks clear and professional and I can find my way around it.

## Why
- The license names one person as the copyright holder, while Mordoc may have more people contribute later.
- The documentation, API demo and change documents repositories have no license at all, so nobody may reuse their content.
- Most repositories have no short description on GitHub, the documentation repository has no README, and the API demo repository links to an old address instead of api-demo.mordoc.dev.

## What
- Every repository has a LICENSE file that names "The Mordoc Authors" as the copyright holder, and an AUTHORS file that lists who they are.
- "The Mordoc Authors" does not mean that every author holds the copyright in all code in the repositories: each author keeps the copyright in their own contributions, as the law already provides. The AUTHORS file therefore only lists the names, without stating this.
- Every repository has a README that says what it is, and a one-sentence description and a few topics on GitHub, written in the same style, so it can be found.
- A repository that publishes a website, such as the documentation and the API demo, links to that website on GitHub.
