# APIs example site

## Description
As a Mordoc contributor, I want a small example website that shows every API reference feature, so that I can see API pages working in one place.

## Why
- There is no single place to see API pages working.
- The [browser tests for this site](../test-e2e-apis/proposal.md) need a site to test.

## What
- A small example site that shows every API reference feature.
- One of four example sites, next to [components](../feat-examples-components/proposal.md), [themes](../feat-examples-themes/proposal.md) and [localization](../feat-examples-localization/proposal.md).
