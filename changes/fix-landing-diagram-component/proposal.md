# Diagrams on landing pages

## Description
As a docs author, I want a diagram on a landing page to display as it does on an article page, so that I can use diagrams on any page.

## Why
- A diagram on a landing page stops the whole site from building. The same site builds without the diagram. Reproduced on 2026-11-06.
- [Catch missing components](../feat-check-tag-component-map/proposal.md) would prevent this kind of bug.

## What
- Diagrams work on landing pages as they do on article pages, and the components example site shows one.
