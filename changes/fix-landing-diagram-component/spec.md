# Diagrams on landing pages: Specification

**Proposal:** [proposal.md](./proposal.md)

## Acceptance Criteria
- **AC-001:** Given a landing page with a diagram, when the site is built, then the build succeeds.
- **AC-002:** Given that landing page, when it is opened, then the diagram displays as it does on an article page.
- **AC-003:** Given the components example site, when its landing page is opened, then it shows a diagram.

## Functional Requirements
- **FR-001:** An author can add a diagram to a landing page.
- **FR-002:** The components example site has a diagram on its landing page.
