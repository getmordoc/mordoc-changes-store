# Mordoc organization on GitHub

## Description
As a Mordoc owner, I want all Mordoc repositories in a shared organization with one recognizable name, so that Mordoc looks like a professional project and we manage it together.

## Why
- One shared name that is easy to recognize and easy to share with others, and that makes Mordoc look professional.
- With all repositories in one organization, settings such as main branch protection and a shared pull request template are managed in one place, for every repository.
- Both owners can manage the organization and its repositories as equals.
- A shared project board can hold the tickets of every Mordoc repository, so the whole team sees one overview of planned and ongoing work.

## What
- A free GitHub organization for Mordoc, with both owners as owners, a short description, and the same name claimed on npm.
- All Mordoc repositories moved into it: the code, the documentation, the app starter and the change documents.
- Links and settings that point to the old addresses updated, so nothing breaks after the move.
- The main branch of every repository protected, so changes only arrive through pull requests.
