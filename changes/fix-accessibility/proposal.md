# Make the site usable with a keyboard and a screen reader

## Description
As a reader who uses a keyboard or a screen reader, I want to use the language picker, the search results and the diagram and image previews, so that I can read every part of a Mordoc site like anyone else.

## Why
- The language picker can only be used with a mouse, so keyboard users can't switch language.
- Screen readers aren't told which search result is selected while a reader moves through the results.
- A diagram's preview can only be opened with a mouse, and a screen reader gets no name for the diagram.
- When a preview opens, the keyboard stays on the page behind it, so keyboard users can't reach its buttons.
- Every reader can use every Mordoc site, and the code check covers accessibility everywhere, without exceptions.

## What
- A language picker, search results and previews that work with a keyboard and tell screen readers what is happening.
- A name for every diagram that screen readers read.
- The code check without the accessibility exceptions that are in the code now.
