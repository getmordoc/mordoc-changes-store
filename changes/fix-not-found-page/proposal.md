# Broken addresses show the host's error page

## Description
As a site reader, I want to see the site's own "page not found" page when I open an address that doesn't exist, so that I can find my way back into the site.

## Why
- The "page not found" page only shows when a reader clicks a broken link inside the site. A reader who opens a broken address directly, from a search result, a bookmark or a link on another site, gets the host's plain error page, with no way back into the site.

## What
- Opening an address that doesn't exist shows the site's own "page not found" page, the same one a reader sees when clicking a broken link.
