# Themes example site

## Description
As a Mordoc contributor, I want a small example website that uses every theming and branding feature, so that I can see a customized site working.

## Why
- There is no site that shows a customized Mordoc working.
- The [browser tests for this site](../test-e2e-themes/proposal.md) need a site to test.

## What
- A small example site that uses every theming and branding feature.
- One of four example sites, next to [components](../feat-examples-components/proposal.md), [localization](../feat-examples-localization/proposal.md) and [APIs](../feat-examples-apis/proposal.md).
- It uses side navigation, because top navigation replaces it. With one language and content pages only, it is close to what a new Mordoc project looks like.
