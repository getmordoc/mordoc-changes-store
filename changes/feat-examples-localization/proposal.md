# Localization example site

## Description
As a Mordoc contributor, I want a small example website that uses every language feature, so that I can see a translated site working.

## Why
- There is no site that shows a translated Mordoc working.
- The [browser tests for this site](../test-e2e-localization/proposal.md) need a site to test.

## What
- A small example site that uses every language feature.
- One of four example sites, next to [components](../feat-examples-components/proposal.md), [themes](../feat-examples-themes/proposal.md) and [APIs](../feat-examples-apis/proposal.md).
- It has English and German, and one page that exists only in English, to show the fallback. Its API pages show how they work today, with English content in every language.
