# Markdown images cause a browser error: Specification

**Proposal:** [proposal.md](./proposal.md)

## Acceptance Criteria
- **AC-001:** Given a page with a Markdown image on its own line, when it is opened, then the browser logs no errors.
- **AC-002:** Given that image, when a reader clicks it, then it opens larger.
- **AC-003:** Given a Markdown image with a title, when the page is opened, then the title shows below the image.
- **AC-004:** Given a Markdown image inside a sentence, when the page is opened, then the image shows and the browser logs no errors.

## Functional Requirements
- **FR-001:** A reader can open any page with a Markdown image with no browser errors.
- **FR-002:** Images look and behave as they do today.
