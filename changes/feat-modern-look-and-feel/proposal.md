# Modernize Mordoc's default look and feel

## Description
As a documentation owner, I want my Mordoc site to look calm and modern out of the box, like the best-known developer documentation, so that readers find their way quickly and trust the product it documents.

## Why
- The sidebar shows all pages as one long list: category names are small and grey, and nothing separates one category from the next, so readers lose their place in larger sites.
- Headings, text and spacing were never tuned together, so pages feel less polished than leading documentation sites, such as Stripe's.
- A clearer default look helps every Mordoc site without any work from its owner.

## What
- A sidebar where each category starts below a thin horizontal line, with a larger and bolder category title.
- Each main heading on a page starts below a thin horizontal line, so a page reads as clear sections; owners who want numbered steps write the numbers in the headings themselves.
- Calmer text colors and spacing for headings, body text and the "On this page" list.
- Dark code blocks in both light and dark mode, so code stands out from the text around it.
- Mordoc's red accent color stays, in light and dark mode.
- Site owners can still change the look with their own styles, as they can today.
