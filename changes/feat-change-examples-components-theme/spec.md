# Journey theme for the components example site: Specification

**Proposal:** [proposal.md](./proposal.md)

## Acceptance Criteria
- **AC-001:** Given the built site, when a visitor goes through every page, then no text, image, video or diagram mentions Orbit, space, planets or stars.
- **AC-002:** Given the built site, when it is opened, then the site is called Mordoc - Components, and the header, the footer and the home page show the journey theme.
- **AC-003:** Given every page, when it is compared with the site before this change, then it shows the same components and variations.
- **AC-004:** Given the images, advanced images and video pages, when they are opened, then the images, captions and video match the journey theme.
- **AC-005:** Given the site, when it is built and opened in light and dark theme, then validation reports no problems and the browser logs no errors.
- **AC-006:** Given the home page, when it is opened in light and in dark theme, then the hero has its own background colour in each, and its title and text are readable.

## Functional Requirements
- **FR-001:** A visitor sees an example website called Mordoc - Components, with content about a journey in four stops, on every page.
- **FR-002:** Every page keeps the components and variations it shows today.
- **FR-003:** Images, captions, the video and the diagram match the theme.
- **FR-004:** The home page hero has its own background colour, in light and in dark mode.

## Non-Functional Requirements
- **NFR-001:** All texts are written for this site, and no names from existing stories are used.
- **NFR-002:** Images and the video are made for this site or come from the Mordoc documentation, and the site stays under 1 MB.

## Boundaries
- Mordoc's own code stays unchanged.
