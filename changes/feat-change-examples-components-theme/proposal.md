# Journey theme for the components example site

## Description
As a Mordoc contributor, I want the components example site to have a theme that fits Mordoc's style, so that it looks like part of Mordoc and not like a generic demo.

## Why
- The site is built around Orbit, a fictional space app, which has nothing to do with Mordoc's style.

## What
- The site is called Mordoc - Components, an example website. Its texts, examples, images, video and diagram follow a journey in four stops to a volcano, instead of the Orbit app.
- Every page keeps the same components and variations; only the theme changes.
- Orbit no longer appears anywhere on the site, and no names from existing stories are used.
