# Links to site files show "page not found"

## Description
As a docs author, I want a link to a file on my site to open that file, so that readers can download it.

## Why
- A reader who clicks a link to a file on the site sees "page not found", although the file exists and its address works directly. Reproduced on 2026-11-06 on the links page of the [components example site](../feat-examples-components/proposal.md).

## What
- Links to files on the site open or download the file, and links to pages work as they do today.
