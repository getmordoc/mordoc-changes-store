# Clearer code structure

## Description
As a Mordoc contributor, I want the code organized by what it does, with clear names, so that I can see at a glance where code belongs and what it may depend on.

## Why
- Similar folders share names, build code and browser code aren't visibly separated, and one very large file holds every component definition.

## What
- Code organized into a small number of clearly named areas, by what it does.
- Code is only moved and renamed, so people using Mordoc notice no difference.
